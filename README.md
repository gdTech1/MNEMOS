# MNEMOS

> A cognitive agent inspired by human memory, semantic association, and memory consolidation.

MNEMOS is an experimental artificial intelligence project that explores how an agent can transform experiences into memories and memories into an evolving knowledge network.

Unlike traditional conversational agents, MNEMOS does not treat conversations as simple text exchanges.

Instead, it attempts to:

- Extract meaningful experiences.
- Create structured memories.
- Organize concepts into a semantic graph.
- Identify relationships between memories.
- Revisit previous memories.
- Suggest new associations through a simulated dreaming process.

---

## Core Idea

Human memory is not a static database.

During wakefulness, the brain:

- Encodes experiences.
- Creates associations.
- Stores temporary memories.

During sleep, the brain:

- Reorganizes information.
- Reinforces important memories.
- Identifies patterns.
- Creates new connections.

MNEMOS applies these principles to an artificial cognitive system.

## MVP

The first version of MNEMOS will implement six core features.

### Conversational Agent

- Receive user input.
- Generate responses.

### Memory Creation

- Extract relevant information.
- Transform experiences into memories.

### Concept Extraction

- Identify entities.
- Identify topics.

### Knowledge Graph

- Create semantic relationships.
- Organize knowledge.

### Dream Mode

- Analyze memories.
- Detect patterns.
- Suggest new associations.

### Graph Visualization

- Display memories and relationships visually.
