# Dream Mode

## Purpose

Dream Mode is the memory consolidation mechanism of MNEMOS.

Its purpose is not to modify memories automatically.

Instead, it analyzes existing memories, identifies potential relationships, and suggests new associations to the user.

All changes must be explicitly approved.

---

# Biological Inspiration

During sleep, the human brain:

- Replays experiences.
- Strengthens important memories.
- Identifies patterns.
- Creates associations.
- Consolidates knowledge.

Dream Mode is inspired by these mechanisms.

---

# Design Principle

MNEMOS never changes memories autonomously.

Dream Mode can only:

- Suggest.
- Analyze.
- Reorganize.

The user always has the final decision.

---

# Trigger Mechanisms

## Temporal Trigger

Memories should be periodically reviewed.

Example:

```text
Memory created

↓

7 days

↓

Dream Mode review
```

---

## Similarity Trigger

Dream Mode should identify semantically related memories.

Example:

```text
Python

↓

Machine Learning

↓

Neural Networks
```

---

## Graph Proximity Trigger

Memories located near each other in the knowledge graph should be analyzed together.

Example:

```text
Neuroscience

↓

Memory

↓

Cognition

↓

Artificial Intelligence
```
