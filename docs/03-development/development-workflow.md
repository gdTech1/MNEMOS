# Development Workflow

## Development Philosophy

MNEMOS follows a documentation-first approach.

Code must never be written before the corresponding documentation exists.

---

# Development Cycle

```text
Research
        ↓

Documentation
        ↓

Architecture
        ↓

Implementation
        ↓

Testing
        ↓

Validation
```

---

# Development Principles

## 1. Cognition before implementation

Cognitive models must always be defined before coding.

---

## 2. Human supervision

The system must never modify memories without explicit user approval.

---

## 3. Explainability

Every memory, concept, and relationship must be explainable.

---

## 4. Modularity

Each component must remain independent.
