# MVP

## Objective

Validate the central hypothesis of the project.

> Can an artificial agent reorganize memories and generate new semantic associations?

---

# Scope

The MVP intentionally limits the project's complexity.

---

# Features

## Conversational Agent

Status: Required

- Receive user input.
- Generate responses.

---

## Memory Creation

Status: Required

- Extract experiences.
- Create memories.

---

## Concept Extraction

Status: Required

- Identify entities.
- Identify topics.

---

## Knowledge Graph

Status: Required

- Create nodes.
- Create relationships.

---

## Dream Mode

Status: Required

- Analyze memories.
- Detect patterns.
- Suggest new associations.

---

## Graph Visualization

Status: Required

- Visualize memories.
- Visualize relationships.

---

# Out of Scope

The MVP will not include:

- AGI.
- Consciousness.
- Biological neural simulations.
- Autonomous decision-making.
- Automatic memory modification.

---

# Success Criteria

The MVP will be considered successful if it can:

- Transform experiences into memories.
- Organize knowledge.
- Suggest meaningful associations.
- Allow user-controlled memory consolidation.
