# Memory Importance

## Purpose

Determine the relevance of a memory.

---

# Importance Scale

```text
1 → Very low importance

10 → Very high importance
```

---

# Scoring Factors

## Frequency

How often the memory is revisited.

---

## Emotional significance

The sentiment associated with the memory.

---

## Project relevance

Whether the memory contributes to an active objective.

---

## User interaction

How often the user interacts with the memory.

---

# Score Updates

Importance scores are dynamic.

They can increase or decrease over time.

---
